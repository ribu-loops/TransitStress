# Contributions and AI assistance

TransitStress is an author-directed student project. Repository history and
dated task/review records are the evidence for its development. Original
project work comprises the experiment design choices recorded in the protocol,
data selection/provenance checks, preparation/injection/masking orchestration,
paired evaluation, bounded runner/artifacts and local/offline interface.
The BLS algorithm, upstream TESS calibration/correction, astronomy libraries and
JavaScript plotting library are third-party contributions.

OpenAI Codex assistants materially assisted planning, implementation, fixtures,
debugging, documentation and recorded model reviews. Other provider/tool use
must be attributed only where the actual historical record establishes it.
Exact serving-model identifiers are not consistently available. Model review
does not constitute external human scientific validation or institutional
endorsement. Tests and independent calculations supply bounded evidence;
neither a model nor a scanner certifies correctness or security.

There is no runtime LLM, custom model training or paid API requirement.
The author is responsible for deciding what to publish, checking citations and
licenses, and being able to explain the code and results. Learning checkpoints
are deferred: no author answers, understanding, personal coding experience,
external users, independent human reproduction or outreach are invented here.

Before a later authorized release, the author must explain the equations, truth
isolation, denominators and one observed failure. Study remains deferred/unassessed.
Private assistant-prepared suggestions are not the author's answers.

Development uses one writer, preserved failures and independent gates. The public
snapshot omits internal operational instructions; its provenance and limitations
are explained in docs/public/REPRODUCIBILITY.md. No push/deployment/outreach is implied.
